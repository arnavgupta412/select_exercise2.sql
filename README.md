# Exercise 2 — SQL Joins & Aggregations

## Overview

This repository contains my solutions for Exercise 2: SQL Joins & Aggregations.

In this exercise, I worked with existing employee and department tables to practice SQL queries involving joins, aggregate functions, grouping, filtering, and sorting.

## Learning Objectives

- Understand SQL JOIN operations.
- Perform SELF JOIN and LEFT JOIN.
- Use aggregate functions such as COUNT(), SUM(), AVG(), MIN(), and MAX().
- Group records using GROUP BY.
- Filter grouped results using HAVING.
- Sort query results using ORDER BY.

## Exercises Completed

| Exercise | Description | SQL Concepts |
|---|---|---|
| 1 | Employees and Department Budgets | INNER JOIN |
| 2 | Employees and Their Managers | SELF JOIN, LEFT JOIN |
| 3 | Employee Count by Department | COUNT, GROUP BY |
| 4 | Average Salary by Department | AVG, ROUND |
| 5 | Salary Summary by Department | MIN, MAX, SUM, COUNT |
| 6 | Departments with More Than Two Employees | HAVING, GROUP BY |
| 7 | Department Budget and Salary Comparison | JOIN, SUM, GROUP BY |
